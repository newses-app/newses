# rss-reader

Self-hosted, multi-user RSS reader and Tiny Tiny RSS replacement. Runs on Docker or AWS, with web, desktop, and mobile clients.

Documentation: [docs/](docs/) — start with [requirements](docs/requirements.md) and [architecture](docs/architecture.md). To run it, see [self-hosting](docs/self-hosting.md).
